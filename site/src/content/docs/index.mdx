# Getting Started with MaxxVim

Welcome to **MaxxVim**! This guide will help you get up and running MaxxVim, the ultimate Neovim distro for the VimMaxxers.

## What is MaxxVim?
~~MaxxVim is a modern, modular, and highly customizable Neovim configuration designed to boost your productivity and make your editing experience delightful.~~
MaxxVim is the Neovim distro for VimMaxxers who care about the best VimMaxxing experience.

## Prerequisites
- [Neovim](https://neovim.io/) (latest version is recommended)
- [Git](https://git-scm.com/)

## Installation
1. **Backup your current Neovim config (optional):**
   ```sh
		mv ~/.config/nvim ~/.config/nvim.back
   ```
2. **Clone MaxxVim:**
   ```sh
   git clone https://github.com/shubhisroking/maxxvim.git ~/.config/nvim
   ```
3. **Start Neovim:**
   ```sh
   nvim
   ```
   Plugins will be auto-installed upon launch with lazy.

## Usage
- Explore the pre-configured keybindings and plugins.
- Customize your setup by editing the configuration files in the `lua/config` and `lua/plugins` directories.

## Troubleshooting
- If you encounter issues, try running `:Lazy sync` inside Neovim to update plugins.
- Check the [README](https://github.com/shubhisroking/maxxvim) for more details.
